# 农场地块坐标

地图由无限延伸的单元组成。每个单元固定 **3 列 × 3 行，共 9 个地块**。房屋与院前田共用中心单元的中央地块；房屋是固定的视觉锚点，院前田仍按原有农事规则运作。

| 名称 | 定义 | 例子 |
| --- | --- | --- |
| 全局地块 `(x, y)` | 整数坐标；`x` 向东（屏幕右）增加，`y` 向南（屏幕下）增加；跨单元不重置 | `p4q1` 表示 `(4,1)` |
| 地块 ID | `p{x}q{y}`，负坐标保留负号 | `p-1q2` |
| 单元 `(u, v)` | `u = floor((x-1)/3)`，`v = floor((y-1)/3)` | `p4q1` 属于 `(1,0)` |
| 单元内位置 `(a, b)` | `a = x - (3u+1) + 1`，`b = y - (3v+1) + 1`，均为 `1..3` | `p4q1` 位于 `(1,1)` |

中心单元是 `(0,0)`，地块范围为 `p1q1` 至 `p3q3`。中央的 `p2q2` 是院前田和房屋位置，世界画面坐标为 `(0,0)`，也是初始镜头中心。向东相邻单元是 `(1,0)`，包含全局 `x=4..6`；向西相邻单元是 `(-1,0)`，包含 `x=-2..0`。例如 `p0q2` 属于西侧单元，单元内位置为 `(3,2)`。

画面坐标只用于排版，不写入存档：同单元相邻地块中心横向相距 212 画面单位、纵向相距 180；相邻单元中心横向相距 672、纵向相距 576。地块之间的道路、水渠和桥属于连续地面装饰，不占用九个地块坐标。镜头可以拖到任意单元，未探索地块仍按同一坐标规则显示，实际探索后才进入游戏状态。

规则层使用 `core/src/game/model/farm-coordinates.ts` 计算单元边界；画面层使用 `assets/scripts/view/FarmDistrict.ts` 映射到屏幕。`tools/test-ui.mjs` 检查边界、负坐标、每单元九格以及房屋中心。
