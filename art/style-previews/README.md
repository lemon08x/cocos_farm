# 农场界面三种风格预览

这三张是从现有农业玩法重新组织的视觉概念图，不是 Cocos 实际运行截图，也没有接入项目。生成时没有使用旧场景或旧界面作为参考图。日期、资源和田况是用于说明信息层级的示例。

| 预览 | 核心视角 | 画面与图标 | 玩法重点 |
| --- | --- | --- | --- |
| `01-field-strategy.png` | 田地总览 | 现代桌游式俯视地图；统一几何线面图标 | 看清不同田况，先选田，再查看农事 |
| `02-season-journal.png` | 四时农历 | 植物手绘纸本；统一单色手绘图标 | 看播种窗口，为田地安排计划，到期手动执行 |
| `03-pixel-farm-desk.png` | 今日农事 | 同像素尺度的场景、边框与图标 | 区分可查看的操作和未到期任务；执行前看条件与报价 |

## 生成提示词要点

均使用内置 `image_gen` 的 `ui-mockup` 模式，输出完整竖屏中文游戏界面；不引用旧美术布局。

1. **田格策略**：以十二块状态不同的田地为主视觉；选中田块高亮；顶部显示日期、钱、口粮、压力；下方显示所选田况、农事入口和待办提示。象牙白、松绿、麦黄配色；底部四个同规格几何矢量图标。
2. **四时手账**：以雨水、惊蛰、清明的纵向农时轴为主视觉；小麦播种窗口、院前田和“加入计划”卡片；清楚标出“到期后手动执行”。暖纸、植物水彩、铅笔线；底部同笔触手绘图标。
3. **像素农事台**：以三种田况的横向像素场景和“今日农事”操作面板为主视觉；未到期事项禁用，查看农事先展示条件与报价。松绿、琥珀、泥土色；场景、边框和四个导航图标保持同一像素尺度。

第三张生成后又进行一次局部编辑，去掉了模型自行填写的行动耗时、物资和压力数值。这些概念图只用于选定视觉与布局方向；实际数值和行动可用性仍应从游戏观察数据读取。
