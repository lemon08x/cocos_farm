# 田园场景 (Scenic) 美术与资产规格 · v2

日期：2026-09-28。状态：当前生效规格，依据[第二版纠偏与实施计划](../../../docs/farm-scene-v2-recovery-plan.md)制定。

> [art/scenic/SPEC.md](../SPEC.md)（v1）为**历史规格**：其中的固定 2:1 投影、260×130 菱形地块、角点河流连接约定**不再适用**于新版素材，仅作为旧版 current 场景与首批素材的存档参考。新素材一律以本文件为准。

视觉基准：`art/expansion-previews/02-district-browse.png`；场景标准图：`art/scenic/revision-2/standard/courtyard-standard.png`（风格、笔触、光照与构图的唯一标准）。

## 1. 投影与几何（绑定）

- Scenic projection：逻辑坐标 (x,y) → 世界像素（zoom 1，y 向下）：
  `wx = (x − y) · 150`，`wy = (x + y − 4) · 90`。
  基准田 p2q2 位于世界原点 (0,0)。
- **地面单元菱形（full cell diamond）**：300×180（半幅 150×90）。相邻逻辑单元中心间距即 150（东西错向）/ 90（南北向）步进。
- **地块耕作四边形（plot quad）**：显示 228×142，半幅 114×71，中心与所在单元菱形中心重合。
  单元菱形与地块四边形之间、以及相邻地块四边形之间留出约 40–70px 的**环境带（environment belt）**：道路、田埂、花草、河岸全部位于环境带内，**绝不画进地块四边形**。
- 光照：晨光来自左上；短影投向右下。直立物（房屋、树、桥、栅栏、指示牌）竖直绘制，仅落地点服从斜面投影。
- 显示尺寸为 zoom 1 尺寸；源图与导出 PNG 为显示尺寸的 2 倍。

## 2. 画布模板（绑定）

### 2.1 地块四边形画布（456×284 源图）

绘制内容为一个近方形斜向四边形，四角**几乎触及**画布四边中点：

| 角 | 位置 |
| --- | --- |
| 上 | ≈(228, 2) |
| 右 | ≈(454, 142) |
| 下 | ≈(228, 282) |
| 左 | ≈(2, 142) |

四边形之外必须透明。叠加层（作物、田埂、花草）与土壤共用同一轮廓模板，层间不含土壤底色。

### 2.2 河流画布（600×360 源图）

整幅地面单元菱形，四角 ≈(300,2)、(598,180)、(300,358)、(2,180)。**水面通过共享边中点衔接，绝不走角点**。600×360 画布的四个边中点（源图像素）：

| 边 | 中点 |
| --- | --- |
| 左上边（上角—左角） | (150, 90) |
| 右上边（上角—右角） | (450, 90) |
| 左下边（左角—下角） | (150, 270) |
| 右下边（右角—下角） | (450, 270) |

- `env.river.straight`：水带从左边相关边中点进入、对侧边中点流出，沿单元长轴方向（左—右）。
- `env.river.straight.y`：沿短轴方向（上—下）的直段，独立素材，不做运行时旋转。
- `env.river.corner`：水带从一个边中点进入，弯转 90° 后从相邻边中点流出。
- 相邻河段在共享边中点处水面与岸坡必须连续，不允许断口；水面宽度在各段接口处保持一致。

## 3. 锚点（anchor）

Manifest 中 `anchor` 为归一化 [ax, ay]，表示图片内对齐到世界落点的位置。地面四边形/菱形素材为 `[0.5, 0.5]`；直立物底部对齐，具体值见 §5。放置：`node.position = worldPoint − [ax·w, ay·h]`（以显示尺寸计）。

alpha 模式定义（与导出脚本一致）：

- `quad`：画布四角透明；几何中心必须有绘制内容（alpha ≥ 128）。
- `quad-overlay`：画布四角透明；整幅平均 alpha > 8（确为有效叠加层）。
- `quad-hollow`：画布四角透明；中心应保持透明（田埂仅描边）。
- `edge`：画布四角透明（直立物背景透明）。
- `opaque`：全图最低 alpha ≥ 250。

## 6. Manifest 与导出（绑定）

```json
{
  "version": 1,
  "id": "scenic",
  "name": "田园场景 · 第二版",
  "palette": { "ink": "#213d2c", "...": "..." },
  "images": {
    "<slot>": { "file": "kebab.png", "width": 228, "height": 142, "anchor": [0.5, 0.5] }
  }
}
```

- `width`/`height` 为 zoom 1 显示尺寸；磁盘 PNG 为其 2 倍。
- 源图目录：`art/scenic/revision-2/sources/`（HUD 图标 SVG 仍读自 `art/scenic/sources/icons/`）。
- 导出：`tools/process-scenic-art.mjs` → `assets/resources/art-packs/scenic/`（PNG + manifest.json + Cocos `.meta`）。
- 校验：源图缺失即失败；宽高比与槽位偏差 > 4% 即失败（**禁止 `fit:'fill'` 拉伸透视素材**，仅 cover 等比缩放）；透明契约按 §5 alpha 模式逐项检查；`ground.base` 必须全不透明。
- 缺失素材回退（供运行时代码）：其他作物 → `crop.default.*`；未知地貌 → `field.unknown`；缺失环境件整体省略该装饰节点。**显式回退，绝不崩溃。**

## 7. 透明背景与抠图流程

1. 生成时即要求透明背景（alpha 通道）；棋盘格图案画在像素里**不等于**透明，导出前实际检查 alpha。
2. 纯色背景（chroma-key）抠除仅用于背景与主体可清晰分离的图；必须人工复核半透明边缘、浅色花瓣、细叶、水面反光，不能无条件阈值抠除。
3. 抠图后在统一灰/绿底上检查黑边、白边与杂色描边；发现问题回到生成或重新抠图，不用描边遮盖。
4. 带明显光影的素材（河流、桥、建筑）不随意翻转复用；需要新朝向就生成新素材（如 `env.river.straight.y`）。
5. 禁止非等比拉伸凑轮廓；模板变更时调整素材或重新生成。
6. 出图后保存原始文件、提示词、参考、裁切与处理步骤到 `generation-records/`；禁止覆盖唯一原稿（原始文件存 `generation-records/raw/`）。

## 8. 生成输入包（每个素材）

1. 原始目标参考图 + 场景标准图（`standard/courtyard-standard.png`）。
2. 同批相邻素材（统一笔触、色彩、光照、细节尺度）。
3. 画布模板（§2：轮廓、连接边/边中点、锚点、可绘制与裁切范围）。
4. 实际显示尺寸、导出尺寸与 2× 倍率（不写“高清”）。
5. 内容清单与排除项（如土壤不含作物与道路、指示牌牌面留白、河段不自行加桥）。
6. 透明背景要求与必须保留的阴影、行间透明、边缘细节。
