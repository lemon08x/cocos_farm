# 画布模板说明 · revision-2

本目录承载各素材的几何模板（轮廓、连接边、锚点、可绘制/裁切范围）。所有坐标为**源图像素**（显示尺寸 2 倍），与 [../SPEC.md](../SPEC.md) 绑定。生成素材时按本文件逐项核对，不用旧版 2:1 / 260×130 / 角点连接参数。

## 模板 A · 地块四边形（quad，456×284）

适用槽位：`field.soil.dry`、`field.soil.wet`、`field.unknown`、`field.ridge`、`crop.wheat.growing`、`crop.wheat.mature`、`crop.default.growing`、`crop.default.mature`、`env.flowers`。

- 画布 456×284（显示 228×142，半幅 114×71）。绘制的近方形斜向四边形四角几乎触及画布四边中点：
  - 上角 ≈(228, 2)，右角 ≈(454, 142)，下角 ≈(228, 282)，左角 ≈(2, 142)。
- 四边形之外**全部透明**。边缘允许 1–2px 柔和过渡，不允许把环境带内容（道路、河流、栅栏）画进四边形。
- 锚点 [0.5, 0.5]：画布中心即世界落点（所在单元菱形中心）。
- 土壤/未知/湿土（`quad`）：四边形内部实心绘制，中心 alpha ≥ 128。
- 作物/花草（`quad-overlay`）：行间与外部透明，不含土壤底色，可无损叠在任一土壤上。
- 田埂（`quad-hollow`）：仅沿四边形四边的草埂条带，中心保持透明。

### 各槽位内容 / 排除清单

| slot | 必须包含 | 不得包含 |
| --- | --- | --- |
| field.soil.dry | 浅棕翻耕土、沿长轴犁沟、细碎土块 | 作物、幼苗、道路、积水、描边框 |
| field.soil.wet | 深棕湿泥、局部水光反射 | 成片积水水田、作物、道路 |
| field.unknown | 雾中荒地、低饱和杂草与土块 | 可辨认的地貌资源、田框、作物 |
| field.ridge | 四边草埂条带（绿色草坡质感） | 中心填充、土壤底色、道路 |
| crop.wheat.growing | 绿色幼苗麦行，行向沿长轴 | 土壤底色、第二层田框、成熟穗 |
| crop.wheat.mature | 金色成熟麦行，穗头可读 | 土壤底色、收割后残茬 |
| crop.default.growing | 通用绿色幼苗（非麦特征） | 土壤底色、作物名牌/文字 |
| crop.default.mature | 通用成熟叶菜 | 土壤底色、果穗特写 |
| env.flowers | 白色/浅色小花与草簇点缀 | 土壤底色、大面积铺满花毯 |

## 模板 B · 河流单元（river，600×360）

适用槽位：`env.river.straight`、`env.river.straight.y`、`env.river.corner`。

- 画布 600×360（显示 300×180，整幅地面单元菱形），菱形四角 ≈(300, 2)、(598, 180)、(300, 358)、(2, 180)。
- **水面经共享边中点衔接，绝不走角点**。四个边中点（源图像素）：
  - 左上边中点 (150, 90)；右上边中点 (450, 90)；左下边中点 (150, 270)；右下边中点 (450, 270)。
- 菱形之外全部透明；锚点 [0.5, 0.5]。
- 水面宽度在进出边中点处保持一致；两岸为草坡+小石块，岸坡在接口处连续。

| slot | 连接口 | 必须包含 | 不得包含 |
| --- | --- | --- | --- |
| env.river.straight | 左/右方向两个对侧边中点进出（沿长轴） | 贯通水带、两岸草坡、流向可读 | 桥、瀑布、断口 |
| env.river.straight.y | 上/下方向两个对侧边中点进出（沿短轴） | 同上，独立绘制短轴透视 | 由 straight 旋转/翻转得到 |
| env.river.corner | 相邻两个边中点进出（90° 弯） | 平滑弯转、弯道内外岸坡 | 直角折线、角点进出、桥 |

## 模板 D · 草地基底（opaque，1024×1024）

- `ground.base`：显示 512×512，源/导出 1024×1024，**完全不透明**（最低 alpha ≥ 250），近似可平铺草地，主色接近 palette `base` (#5f8a4e)；锚点 [0.5,0.5]。
- 不得包含：明显方向性光影、单点大树/建筑、可读图案（平铺时会产生重复感）。

## 模板 E · HUD 图标（edge，128×128）

- 11 个图标（`icon.date/coin/food/pressure/arrow/todo/seedling`、`nav.field/calendar/basket/more`）：沿用 `art/scenic/sources/icons/` 现有 SVG，深绿 (#2e5240) 实心剪影，透明背景，64×64 显示 / 128×128 导出，锚点 [0.5,0.5]。本轮不改动字形。
