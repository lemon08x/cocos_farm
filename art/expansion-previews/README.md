## 生成提示词要点

使用内置 `image_gen`，以 `01-field-strategy.png` 和已有连续地图预览为美术品质参考，分别生成不同构图的完整竖屏 `ui-mockup`。三张均要求精细手绘土壤、作物、植被、水渠和统一图标；顶部保留日期、钱、口粮、压力，底部保留所选田块与农事入口；不得沿用封闭的 3×4 田格布局，也不得凭空填写行动成本。

1. **连续拖动**：视口裁切一张向四周连续生长的农田地图；田格、道路和水渠穿过画面边缘，提供局部定位和缩放控件。
2. **分区浏览**：当前田区与东侧、南侧相邻田区自然衔接；用田区导航、路牌和淡出边缘的局部地图表达跨区浏览。
3. **缩放总览**：将主地图镜头拉远，形成约 6～7 列、6～7 行可辨认的地块；不同田况仍可识别，田野在视口外继续延伸。

图中文字和田况用于评估美术与布局；实际游戏数据、地块扩展规则和操作可用性应由游戏状态提供。
